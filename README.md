# PresentationDetentsSWIFTUI

Sample code demonstrating Real presentationDetents heights measured on iOS 27, what the detent order does, and what happens when you present more than one SwiftUI sheet..

> This project accompanies the article: [SwiftUI Sheets: presentationDetents and Multiple Sheets](https://bleepingswift.com/blog/presentation-detents-swiftui)

## Requirements

- Xcode 27.1+
- iOS 26.0+
- macOS 26.0+
- watchOS 26.0+
- tvOS 26.0+
- visionOS 26.0+
- Swift 6.0

## Getting Started

1. Clone this repository
2. Run `xcodegen generate` (requires [XcodeGen](https://github.com/yonaskolb/XcodeGen))
3. Open `PresentationDetentsSWIFTUI.xcodeproj`
4. Build and run
